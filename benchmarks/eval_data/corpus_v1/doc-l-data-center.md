# Data Center Infrastructure Codes

This document defines the asset codes used at Acme's data center. The codes are deliberately confusable and appear in multiple places, so answers should quote the exact code.

- Rack cooling unit: code "CRAC-7", not "CRAH-7".
- UPS battery station: code "UPS-B", not "UPS-P".
- Network switch layer: layer "L3-Edge", not "L3-Core".
- Power distribution unit: code "PDU-9".

Sensor telemetry wiring conventions:
- Temperature sensor on rack 3 connects to port "T-03".
- There is no sensor wired to rack 9; rack 9 is a placeholder rack with no active instrumentation.

Asset counts: 14 cooling units, 28 network switches, 9 UPS battery stations.

The data center uses code "DC-EAST". There is a similarly named but different code "DC-WEST" that does not exist in this facility.
